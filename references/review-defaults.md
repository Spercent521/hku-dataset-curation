# HKU 年度审核默认规则

用于 HKU 年度批次的归档与人工接续。用户明确指定的处理办法优先。以下默认只帮助确定已有材料的去向，不产生新的医学事实。

## 归属与分类

- **姓名优先，病例号兜底。** 用已有索引和来源确定归属，不把姓名或病例号当作全局唯一键。同一人原件上的不同号码照录；明确不同的人即使共号也分开归档。同名有具体冲突时也不自动合并。有可靠姓名但找不到既有病例时，可按原姓名建档，不补病例号。
- **单人材料沿用已有归属。** 单人课件中的相近写法、拼音、简称或脱敏称呼，在没有实质身份冲突时按主病例处理。患者目录明确且未发现混入他人材料时，可沿用整组原件的归属，不要求每个对象另有姓名。保留原有编号、年龄、性别与日期差异；不能据此认定同次就诊。多人课件或名册按实际病例段落或行拆分，不把主病例身份套到其他人。无身份线索的散件不猜。
- **先归能确定的内容。** 按原件推进，有明确去向就归档并记来源；同一病例来新材料是追加，不是冲突。只回查直接相关的冲突，不重扫全年、不逐例重复验八阶段。原件保管位置与其中个别对象的归档判断分开记录；局部待核不妨碍已明确内容归档。
- **阶段明确就归档，不追问无关精度。** 已知是术后复查就归入该阶段，不追问准确日期、随访间隔或不影响去向的手术场次。固定物只能在已知同次手术语境中作为线索，不能单凭有无固定物判定术前、术中或术后。测值和改善率按原位置照录，不补算、不从数值推断阶段或手术效果。
- **仅限 2017 的汇报名册：** `Procedure` 栏按已实施记录，病例归属另判。明确写拟行或规划、或有相反证据时以原文为准。不补手术日期、顺序或场次；不把该约定套到其他年份的一般治疗栏或术式栏。

## 只把可回答的例外交给人工

- 先用已有台账和上述规则分流。没新证据、人工也无从判断的单独暂挂；保留原文、来源位置和状态，不反复派问。
- 只问有可核对线索、答案会改变归档结果的问题。按原件或同一冲突合并，一次列齐该组的本地链接、页码或位置、问题和回答选项。哈希和内部日志留在台账。答复后按结论归档、记账、移出活动清单；「看不准」单独暂挂，不再追问。
- 分开报告已结清原件数、暂挂原件数和待答问题组数。已处理的局部内容不等于整份原件结清。

## 发布版的缺项 README

当用户明确采用 2017、2018 的发布口径时，按交付版八阶段目录统计没有交付文件的阶段，忽略系统文件与占位文件。以「未提供的记录有：」开头，按病例、阶段和通用记录名列树；不推断原始材料不存在、临床未发生或结果为阴性。具体的未读、冲突、待核和质量排除项留在内部台账，不作为独立缺项写入 README。未采用这一发布口径的批次仍按[样例与输出规范](sample-standard.md)确认缺项。
